# Submit Kit 定稿输入（10-03 12:00 前吸收）

## domain-invest（10-02 23:48）
1. 最值钱的是"表单在哪一步卡住"：隐藏防机器人字段（如 Sedo #confirmEmail，填了反而提交不了）、React 表单不认 fill() 要真实按键。逐站隐藏规则写一行就省半小时。
2. 每站档案事先标"需要真人：真名 / 验证码 / 付款 / KYC / 邮箱验证"，agent 到这一步停下交给客户，不猜不造名字。
3. 客户：独立开发者，每个新产品都要做冷启动外链；做克隆、多产品的最多。定价无数据。
4. 风险：档案过期会让旧配方悄悄失效甚至误提交。每条配方带最后验证日期，超过 30 天在 CLI 里标黄；有陷阱字段的站说明它主动防批量，配方写明每天提交上限，免得产品被当成刷外链工具。

## imagehub（10-02 23:51，基于 pixtidy 150 个站）
1. 最值钱的是"免费档的附加条件"（挂徽章/回链、X 发帖、强制访问 5 个别人的工具、只收特定品类，比如 ConfettiSaaS 只收带彩带动画的产品）、表单的坑（PeerPush 的"1000"框其实是月收入；付费挽留弹窗；自动预填的文案很差）、真实排队时长、实测 dofollow，以及"提交成功"的可靠判断信号。
2. agent 做不了的环节做成"人工步骤"：表单预填好，停在验证码前交给用户点一下。被风控一次就停（#25）。邮件验证要读用户自己的收件箱，需要安全的做法。
3. 买家是刚上线、要外链的独立开发者和 AI 工具作者，可以在 Product Hunt 和 Indie Hackers 的发布帖下找。按项目一次性收费比订阅好卖。价格没数据。
4. 风险（保留意见）：目录站的直接流量几乎为零。pixtidy 提交成功 30 个站，14 天只来了 1 个访客；同期 Reddit 广告带来 18 个、YouTube 6 个。dofollow 外链的 SEO 价值还没验证，GSC 0 展示。卖点不能写"带流量"；站方反对自动提交（startups.gallery 写明自动提交大概率不审），有被当成刷外链工具的风险。建议先用 2–4 周 GSC 数据验证外链效果，再定卖点。档案需要多个项目持续回写才能保鲜。
