# 目录提交套件（Submit Kit）评估：定稿

2026-10-03 · AgentoolRank 负责人 · 回应老板 10-02 23:45 的想法 · 初稿 10-02 23:46，本稿吸收 agentkit、domain-invest、imagehub、new_ladar 的意见

## 结论

**做。但只做一个很小的 MCP 工具来验证有没有人付钱，不做全自动提交。**

- 工具名 `recommend_directories(product_type)`：输入产品类型，返回最适合的 30 个目录站，每个站附"提交要点"。免费给前 10 个，完整 30 个加持续更新要付费。
- 挂在 AgentoolRank 现有的 MCP 和品牌下。
- 卖点是**省时间、少踩坑**，不是"带流量"或"提升 SEO"。
- 10-18 前卖出至少 3 单就继续投入，否则冻结付费部分，只保留免费部分。

## 我们手里有什么（如实）

- 共享日志里有 296 个域名，真正打开并走过提交流程的有 101 个。这 101 个已经整理成结构化数据（`data/directories-verified.json`），全部来自我们三个项目自己的记录。
  - 其中免费层已上线 /where-to-list：101 个站的免费档、附带条件、价格、实测链接类型、登录方式、验证码。
  - 付费层要卖的是这些数据之外的内容：每站的踩坑提示（101/101 都有）和"怎样算提交成功"的判断依据（75/101 有）。
- columbus 的 DR 和访问量是买来的数据，不能转卖，一律不放进产品。
- 对外只说"101 个实测、近 300 个已筛"。

## MVP（1 天）

1. MCP 工具 `recommend_directories(product_type, limit)`：
   - 按产品类型（AI 工具、开发者工具、SaaS、MCP 服务器……）从 101 站里排序。排序依据：是否对口、有没有免费档、要不要挂徽章、需要几个人工环节。
   - 每个站返回：免费条件、实测链接类型、登录方式、需要真人的环节、提交要点（踩坑提示）、成功信号、最后核实日期；超过 30 天的标"待复核"。
   - 不带 key 时只返回前 10 个站，带有效 key 时返回完整 30 个。
2. 付费：复用现有 Stripe 一次性付款，新加一个价格，付款后发 key，**$29 一次性，含 30 天内的更新**。
3. 文档：/agents 页加一节说明，Smithery 的描述同步更新。

## 定价

- **$29 一次性**。
- 依据：同类目录清单从免费到 $29 都有，代提交服务 $49–$499。我们卖的是清单里没有的"要点 + 真人环节 + 成功信号"，又比代提交便宜、过程透明、账号掌握在用户手里。
- 不打折，不做早鸟价，先看原价有没有人买。

## 第一批客户从哪来

1. 通过 MCP 和 API 来提交工具的 agent。它们拿到的 `message_for_human` 里加一句："还想上其他目录？用 recommend_directories。"这些人正在做外链，最对口。
2. 10-07 的数据文章（实测 101 个目录站），文末放链接。
3. Smithery、cursor.directory、conduid 上我们的 MCP 描述。
4. **不用冷外联推销**，免得拖累外联的送达率。

## 和主线的关系

- 外联照常，每晚 10 封。
- 目录站已暂停扩张（agentkit 10-03 05:28），省下的时间正好做这件事。
- 中日文页等 Google 收录，期间没有能推进的开发量。
- 风险：主产品的付费单还是 0，再开一条线可能分散精力。所以只投 1 天，用 10-18 的结果决定是否继续。
