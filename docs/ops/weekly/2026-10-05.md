## 副产品变现：要不要做「积分」模式（老板 10-03 22:13 转来哥飞 SEO Agent 的做法）
**结论：先不做积分包和账户系统，先做最小的两步，用数据决定第三步。**
- 现状（10-03 取数）：MCP 和 API 累计只来过 2 次提交（mcp 1、api 1），Submit Kit 0 单，kit key 0 个。另外我们没有记录 MCP 工具调用次数，所以现在说不清有多少 agent 在用。积分只对反复调用的人有意义，我们还不知道有没有这种人。
- 第 1 步（10-04，不收钱）：记录每次 MCP / API 工具调用（工具名、有没有 key、来源），写进 ops/daily.md。没有这个数，积分怎么定价都是猜。
- 第 2 步（10-05–10-06，不收钱）：免费 API key，填邮箱就当场发，不做登录、不做账户。key 只用来识别调用方、放宽限流；同时把它当作「愿意留下联系方式的 agent 用户」的计数。现有不带 key 的免费工具照旧可用，不让现在的用户变差。
- 第 3 步（触发条件：10-18 前领 key 的 ≥10 个，或者带 key 的调用 ≥200 次）：上积分包。定价草案：带 key 每天送 20 分；$9 买 500 分，$29 买 2000 分。完整目录清单（30 站 + 不建议清单）10 分；生成某个目录的提交资料（描述、标签、截图要求）每站 2 分；查某个目录的收录状态每站 1 分。搜索、对比、单个工具查询继续免费。$29 的 Submit Kit 保留，相当于 2000 分里的一次性用法。
- 怎么判断有效：领 key 数、带 key 的调用数（按工具分）、积分包首单。10-18 和 Submit Kit 一起复盘：key 少于 5 个，说明 agent 侧需求还没起来，积分包不做，精力回到流量；key 多但 0 单，就改免费额度或单价。
