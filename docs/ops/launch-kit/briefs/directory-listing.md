# Brief: AgentoolRank directory-listing copy set (for submitting to AI tool / startup directories)

## Product facts (only these)
- Name: AgentoolRank. URL: https://agentoolrank.com. Built by Ethan Tan.
- A directory of 669 open-source AI agent tools (agent frameworks, coding agents, MCP servers, RAG and memory, evaluation and observability, browser agents, voice agents).
- Tools are ranked by live GitHub activity instead of star count: 30-day star growth, commits in the last 90 days, releases in the last 6 months, issue response time. Data refreshes daily from the GitHub API.
- Every tool has its own page with stats, an alternatives page and side-by-side comparisons.
- Monthly data report at /report, free to reuse under CC BY 4.0. Finding: 32% of tracked tools have had no commit in 6+ months.
- Public MCP server at https://agentoolrank.com/api/mcp (listed in the official MCP Registry) so Claude, Cursor or any MCP client can search tools, get stats and alternatives. Also a JSON API.
- Free to use, no signup. Makers can list their tool for free (queued review) or pay $9/$19/$49 for faster review / featured placement.
- Chinese pages exist for the top 200 tools.

## Audience
People browsing AI tool and startup directories: developers choosing an agent framework or MCP tool, and makers looking for where to list their own tool.

## Output needed (label each block exactly)
TAGLINE_SHORT: under 60 characters
TAGLINE: under 100 characters
DESC_SHORT: under 160 characters, one sentence
DESC_MEDIUM: 2-3 sentences, under 300 characters
DESC_LONG: about 120-150 words, plain paragraphs, no lists
DESC_LONG_ALT: a second long description with a different opening sentence and emphasis (data/report angle), same facts
FEATURES: 5 short feature lines
USE_CASES: 3 short use-case lines

## Rules
- No hype words, no superlatives we cannot prove ("best", "leading", "#1"), no invented numbers or user counts.
- Write in plain English a developer would use.
