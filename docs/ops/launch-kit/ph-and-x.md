## Product Hunt
- **Name:** AgentoolRank
- **Tagline (≤60):** Pick AI agent tools by activity, not stars
- **Description (≤260):** AgentoolRank ranks 669 open-source AI agent tools — frameworks, coding agents, MCP servers, RAG, evals — by live GitHub activity. Every tool gets alternatives and head-to-head comparisons, and your AI assistant can query it all through a public MCP server.
- **Topics:** Developer Tools, Artificial Intelligence, Open Source, GitHub
- **Gallery (1270×760):** ph-1-home.png, ph-2-report.png, ph-3-alternatives.png, ph-4-compare.png, ph-5-agents.png (re-capture ph-2 before launch so the report header shows the current month)
- **First comment (maker):**
  Hi PH 👋 I built AgentoolRank because I kept choosing agent frameworks by star count and then discovering they hadn't shipped in months. It turns out 32% of the 669 open-source agent tools we track have had no commit in 6+ months — including some with 50k+ stars.
  So every tool here is ranked by what it's doing now: 30-day star pace, commits in the last 90 days, releases and issue response, refreshed daily. Each tool has an alternatives page and side-by-side comparisons, and there's a free monthly data report.
  Two things I'd love feedback on:
  1) The MCP server (agentoolrank.com/api/mcp) — ask Claude or Cursor "what's a maintained alternative to X?" and it answers from live data.
  2) Agent-friendly listing: an agent can submit a tool and get every option back in one response, no upsell flow.
  What would you want a tool directory to measure that stars miss?
