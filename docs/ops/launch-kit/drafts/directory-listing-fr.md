# AgentoolRank, annuaire gratuit d'outils d'agents IA open source

[AgentoolRank](https://agentoolrank.com) vous permet de trouver 669 outils d'agents IA open source, gratuitement et sans inscription. Le classement privilégie l'activité GitHub récente plutôt que le total d'étoiles. Vous pouvez consulter les statistiques de chaque outil, découvrir des alternatives et comparer les outils côte à côte.

## Questions fréquentes sur AgentoolRank

### AgentoolRank est-il gratuit sans inscription ?

Oui. Vous pouvez consulter l'annuaire gratuitement, sans créer de compte.

### Le classement dépend-il du nombre total d'étoiles GitHub ?

Non. Il repose sur l'activité récente. La croissance des étoiles sur 30 jours fait partie des critères, avec les commits, les versions publiées et le délai de réponse aux issues.

### Peut-on rechercher des outils depuis Claude ou Cursor ?

Oui. Le [serveur MCP public](https://agentoolrank.com/api/mcp) permet à Claude, Cursor ou à tout autre client MCP de rechercher des outils et d'obtenir leurs statistiques et alternatives.

### Combien coûte la soumission d'un outil ?

La soumission est gratuite avec examen en file d'attente. Des options à 9, 19 ou 49 dollars sont proposées pour un examen accéléré ou une mise en avant.

### Peut-on réutiliser le rapport mensuel ?

Oui. Le [rapport mensuel](https://agentoolrank.com/report) est réutilisable gratuitement sous licence CC BY 4.0.
