## AgentoolRank 常见问题

### AgentoolRank 按 GitHub 星标总数排名吗？

不按累计星标数排序。它看近 30 天星标增长、近 90 天提交、近 6 个月发布，以及 issue 响应时间；数据每天更新。

### AgentoolRank 免费吗，需要注册吗？

免费使用，无需注册。作者也可以免费提交工具，但需要排队审核。

### AgentoolRank 有中文页面吗？

有，近 200 个热门工具提供中文和日文页面。

### Claude 和 Cursor 能查询 AgentoolRank 吗？

可以通过公共 MCP 服务器查询工具、统计和替代方案。服务器地址是 https://agentoolrank.com/api/mcp，也支持其他 MCP 客户端。

### 月度报告可以转载或复用吗？

可以按 CC BY 4.0 许可免费复用。报告入口是 https://agentoolrank.com/report。

### 怎么把自己的工具提交到 AgentoolRank？

作者可以免费提交工具，提交后排队审核。也可以选择 $9／$19／$49 的付费选项，用于加快审核或推荐展示。
