## What should you know before choosing or listing a tool?

### Does AgentoolRank rank tools by GitHub stars?

Not by total stars. Rankings use 30-day star growth alongside commits in the last 90 days, releases in the last 6 months and issue response time.

### Does "live GitHub activity" mean the data updates continuously?

Data refreshes daily from the GitHub API.

### Does a free tool submission skip the review queue?

No. Free submissions enter queued review. Paid options cost $9, $19 or $49 for faster review or featured placement.

### Can you reuse the monthly report?

Yes. The [monthly report](https://agentoolrank.com/report) is free to reuse under CC BY 4.0.

### Can you search AgentoolRank from an MCP client?

Yes. The public server at [agentoolrank.com/api/mcp](https://agentoolrank.com/api/mcp) lets Claude, Cursor or any MCP client search tools and get stats and alternatives.
