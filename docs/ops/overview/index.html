一句话：网站做好了但没人来，也没有收款的地方。现在的读者只是来看看的访客，他们几乎不花钱；像 PeerPush 这类站，真正付钱的是想被人看到的工具作者。所以下一步是把站点改成"工具作者主动来提交、带着自己的用户来"的双边平台，并加上收款。

PeerPush 为什么流量大，我们能学什么

  1. 付钱的是工具作者，他们也带来流量。作者提交产品后会把页面转发给自己的用户、朋友来点赞。它公布的数字是每月 110 万访问、3.2 万订阅（第三方列表写的是 82 万，都是它自己报的数，大头是作者自己）。→ 我们要做"提交你的工具"入口，给作者一个值得转发的页面和徽章。
  2. 给别人写点评可以换免费上架。每写一条通过审核的点评得 80 分，积分高就能在免费队列里往前排，于是作者每天都回来。→ 抄这个设计，用积分换排队位置。
  3. DR 75 的 dofollow 外链。"100 个上架目录"之类的清单都会推荐它，做 SEO 的人愿意为这个外链付钱。→ 我们的外链权重还很低，现在卖不上价；要先靠作者挂徽章、以及上各种目录清单，把外链积累起来。
  4. 一个商品卖三档：免费（排队）/ $39 立即上线 / $89 推广 7 天 / $229 推广 30 天，另有竞价广告位 $5 起。→ 我们先低价：免费 / $19 快速上线 / $49 首页推荐 7 天，等有流量再涨价。
  5. 每天和每周的榜单（Product of the Day/Week）让作者有转发的理由，站内也有人每天回来看。
  6. AI 能直接读它的数据（MCP 服务器 + API，Claude、Cursor 可以直接查）。→ 这和我们做 AI Agent 工具最对口：做一个 AgentoolRank MCP，上架到各 MCP 目录，本身就能带来外链和开发者。
  7. 程序化 SEO 页型：alternatives、用途、人群、平台。→ 我们已证明对比页有效，下一步补 "X alternatives" 页。

② 接下来怎么做

第 1 周（10-01 ~ 10-07）→ G1

  • 加站内分析：浏览器事件发到自己的 /api/e，由服务端转发，不装第三方脚本（imagehub 的做法）。
  • 做 /submit：作者填网址，AI 自动补全信息，进免费队列；页面上显示排在第几位。
  • 做 "Featured on AgentoolRank" 徽章和挂徽章的说明，挂了徽章的作者排序靠前（这就是外链来源）。
  • 把 AgentoolRank 免费提交到 PeerPush、Peerlist、launch 目录清单这些地方（走免费队列，不付插队费）。

第 2–3 周 → G2

  • Stripe 结账（$19 / $49），带 statement_descriptor_suffix 和 site metadata。前提：你开通了 key，Vercel 换成允许商用的套餐。
  • 对比页全力做：从 GSC 找有曝光的词，补 "X alternatives" 和热门对比，更新旧对比页里的数据。
  • 积分系统：点评别的工具可以换排队位置；每天、每周榜单页。
  • AgentoolRank MCP 服务器 + llms.txt，上架 Smithery、mcp.so、Glama 这些 MCP 目录。
  • 联系 GitHub 排名前 50 的工具作者（每天最多几封，每封单独写）："你的项目上榜了，这是你的徽章"。

第 4 周以后 → G3 / G4

  • 每周自动生成周报并发送；订阅人数上来后卖赞助位。
  • 收费工具加联盟链接；AIMarketRank 继续暂停，等主站跑通再说。
  • 每周一在这页写复盘：数据、做了什么、下周做什么。
